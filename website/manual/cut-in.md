# カットイン

画像・動画・音声による演出（カットイン）を作成・再生します。FABメニューの**メディア**にある「カットイン」から開きます。

## カットインを作る

カットイン一覧から新規作成し、表示する画像／動画（YouTube含む）や音声、表示位置・大きさなどを設定します。

## はじめから入っている見本

新しい部屋には**Sample1**と**Sample2**の2つが置かれています。どちらもキャラクターの登場演出で、顔の画像が枠いっぱいに表示され、効果音が鳴り、隅に擬音の文字が出ます。**目 : 画像を差し替える**という名前のレイヤーの画像を差し替えるだけで、自分のキャラクター用の演出として使えます。不要であれば、一覧から削除して構いません。

## 再生する

- 一覧から選んで再生
- チャット起動を許可したカットインは、チャットの文末に名前を打って再生できます — `名前`で映像つき、`@名前`で**音声のみ**（詳細は[チャットの特殊記法](/manual/chat-syntax#カットイン起動)）
- テーブルを切り替えたときに流すこともできます（[テーブル設定](/manual/table-setting)）

絵は出るのに寄りやワイプが付かないときは、OSの「動きを減らす」設定が効いています。
FABメニューの**表示**にある[アニメーション](/manual/theme#animation)を**常に再生**にしてください。

## 枠なしで流す

表示設定の**枠なしで表示**を入れると、タイトルバーも枠線も背景も消えます。残るのは絵だけ。クリックはそのまま下へ抜けるので、演出が流れている最中でもコマを動かしたり地形を並べ替えたりと、卓の操作を止めずに済みます。

代わりに閉じるボタンがなくなります。終わらせる道は4つ。

- 再生時間（秒）を決めておく
- ループを切って、動画かシーンが終わるのを待つ
- 一覧の**停止**を押す
- 同じタグの別カットインを流して置き換える

ループを入れたまま再生時間を0にすると、出っぱなしになります。誰かが止めるまで消えません。

## レイヤーを重ねて組み立てる

編集画面の**シーン**タブでは、1枚絵ではなく複数のレイヤーを重ねたカットインを作れます。画像・文字・帯の3種類を足し、ステージ上でドラッグして置き、四隅をつまんで大きさを変えます（Shiftを押しながらだと縦横比が保たれます）。

選択したレイヤーの上には丸いつまみが出ます。掴んで回すと傾き、Shiftを押しながらだと45度ずつ止まります。

左のレイヤー一覧は上が手前です。行をドラッグすれば重なり順が変わります。目のアイコンで一時的に隠せますし、錠前を掛けたレイヤーはステージ上でつかめなくなるので、下に敷いた背景を触ってしまう事故を防げます。

帯レイヤーは1色でも、2色を混ぜても構いません。混ぜ方は直線・放射・円錐・縞・集中線・網点の6つで、中間色を1つ挟むこともできます。縞・集中線・網点には**細かさ**（px）と**角度**があり、同じ2色でも荒くも細かくもなります。

レイヤーを1枚でも足すと、そのカットインは「元サイズで表示」をやめます。1枚の画像の寸法に合わせる意味がなくなるためです。

### 形を変える

レイヤーは四角のまま表示しなくても構いません。**切り抜き**を選ぶとレイヤーの外形が変わります。平行四辺形・破れ・裂け目・爆発・星・矢羽根・楕円の7種類から選べます。**傾きX / Y**を加えれば、切り抜いた形ごと斜めに倒れます。

**めくり**と**崩し**は、絵を端から消していく指定です。向きを選んでから、消す量をスライダーで決めます。めくりは切り口がまっすぐ、崩しは切り口が砕けた形になります。この量にはキーを打てるので、0% から動かせば端から捲れていく／崩れていくアニメーションになります。

文字レイヤーには**揃え・縁の色と太さ・字間・行間・フォント**があり、**縦書きにする**を入れれば擬音を画面の端へ縦に流せます。画像レイヤーの**枠いっぱいに切り抜く**は、絵を枠の縦横比に合わせて切る指定です。切ったあとにどこを見せるかはX / Yで決めます。

### 動かす

下のタイムラインが尺です。プロパティ欄の各項目の右にある ◆ を押すと、再生ヘッドの位置にキーが打たれます。あとは再生ヘッドを動かして値を変え、そこでもう一度 ◆ を押すだけ。2つのキーの間をレイヤーが動きます。

キーを打てるのは**X / Y・拡大率・回転・不透明度・ぼかし**です。タイムライン上の ◆ はドラッグで前後に動かせます。消すときはダブルクリック。

キーの上に再生ヘッドがあるときは**補間**の欄が出ます。等速のほか、ゆっくり終わる、行き過ぎて戻る、瞬間的に切り替わる、といった動き方を選べます。選んだ動き方は、その位置に立っているすべてのキーへまとめて書き込まれます。位置と不透明度がばらばらの曲線で動いてしまうのを防ぐためです。

レイヤーごとの**開始ms / 終了ms**を決めれば、途中から出したり途中で消したりできます。終了0は「シーンの最後まで」の意味です。

### 尺を見渡す、拾う

尺が長くなるほど、タイムラインの目盛りは詰まって狙いにくくなります。右上の虫眼鏡ボタンで拡大・縮小できます。Ctrlを押しながらホイールを回しても同じです。真ん中のボタンを押すと、尺全体が収まる倍率に戻ります。

同じ3つのボタンはステージ側にもあり、そちらはステージの拡大・縮小に効きます。小さなレイヤーを置くときに使ってください。

レイヤーの帯は端をつかんで引けば、開始と終了がそのまま変わります。msを打ち込まずに尺を決められます。

キーやSEをドラッグすると、他のキー・SE・帯の端・再生ヘッド・尺の両端へ吸い寄せられます。近さは画面上の距離で測るので、タイムラインをどれだけ拡げても同じ感覚で効きます。あいだの半端な時刻に置きたいときはShiftを押しながら引いてください。

同じ姿を別の時刻にもう一度置きたいときは、Ctrl+Cでその瞬間の姿をコピーし、再生ヘッドを動かしてCtrl+Vで貼り付けます。X / Y・拡大率・回転・不透明度・ぼかしが、まとめてキーになります。

| キー         | すること                                       |
| ------------ | ---------------------------------------------- |
| ← →          | 再生ヘッドを1目盛りずつ                        |
| Shift + ← →  | 前後のキーへ飛ぶ                               |
| Home / End   | 先頭 / 末尾へ                                  |
| ↑ ↓          | 選択中のレイヤーを上下に1px（Altを足して10px） |
| Alt + ← →    | 選択中のレイヤーを左右に10px                   |
| Ctrl + C / V | その瞬間の姿を取る / 置く                      |
| Delete       | 選択中のレイヤーを消す                         |
| スペース     | 再生と停止                                     |

時刻を直接指定したいときは、タイムライン左上の時計の隣に秒を打ち込みます。

矢印で動かした値の書き込み先は2通りです。再生ヘッドの位置にキーがあればそのキーに、なければレイヤー自体の位置に書かれます。プロパティ欄に数字を入力したときと同じ規則です。

### 手で打たずに済ませる

キーを1つずつ置くのが面倒なら、プロパティ欄の**登場 / 退場**から選びます。左から滑り込む、拡大しながら現れる、回りながら入る、落ちて消える——選んだ瞬間にキーが打たれ、あとは普通のキーとして動かせます。長さもmsで指定できます。

**エフェクト**は出ている間ずっと続く小さな味付けです。発光・影・点滅・揺れ・脈打つ・浮遊の6つ。強さは0〜300% で決め、発光だけは色も選べます。

**演出**を選ぶと、登場・退場・エフェクトが一式まとめて入ります。衝撃・見出し・お披露目・不穏・たゆたう・警告・登場・ささやきの8種類。中身はただのキーとエフェクト設定なので、当ててから好きに崩せます。

### 音を置く

ツールバーの**SE**を押すと、再生ヘッドの位置に効果音が1つ置かれます。何個でも置けるので「0.2秒で斬撃、1.5秒で着弾」のような重ね方ができます。タイムラインのSE行でドラッグすれば時刻がずれ、ダブルクリックで消えます。音量はSEの音量設定に従います。

編集画面では再生中だけ鳴ります。再生ヘッドを手で動かしている間は黙っているので、置き場所を探しているうちに部屋じゅうへ音を撒く心配はいりません。

書き出した動画の音は録画のほうから作られるので、ここに置いたSEは動画には入りません。

組み立てたカットインは、[リプレイ](/manual/replay)の動画書き出しにもそのまま出ます。

### やり直し

Ctrl+Zで1手戻り、Ctrl+Shift+Z（またはCtrl+Y）で進みます。ドラッグ1回は、途中で何度画面が動いても1手です。

::: warning 2人で同時に編集すると
シーンは参加者全員で共有されます。同じシーンを2人が同時にいじると、あとから書いたほうが残ります。元に戻す操作も相手の変更ごと巻き戻すので、1人ずつ編集してください。
:::

## 音量

- カットインの動画音量は調整でき、YouTubeの音量はBGMとは独立して管理されます（既定50）

BGM本体の管理は[ジュークボックス](/manual/jukebox)を参照してください。
