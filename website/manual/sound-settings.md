# 音の設定

自分の端末で鳴る音の大きさを、音の種類ごとに決めるパネルです。FABメニューの「表示」の小窓にある「音の設定」から開きます。ジュークボックスの「自分の音量」の横にあるボタンや、チャット設定の発言の効果音の欄からも開けます。スマートフォンでは、メニューの「音の設定」から開きます。

ここで決めた値は自分にだけ効き、このブラウザに保存されます。部屋のデータには入らず、ほかの参加者にも送られません。

## 自分の音量

音の種類ごとに、スライダーが1本ずつあります。

| 種類           | 鳴る音                                                                                                           |
| -------------- | ---------------------------------------------------------------------------------------------------------------- |
| 試聴           | ジュークボックスやカットインの曲選びで、自分だけが聞く音                                                         |
| BGM            | ジュークボックスの音楽                                                                                           |
| 環境音         | 雨や焚き火などのループ（[環境音](/manual/jukebox#環境音)）                                                       |
| カットイン     | カットインの音楽、場面に合わせて鳴る音、YouTube動画の音                                                          |
| 通知音         | チャットの発言の効果音、アラーム                                                                                 |
| 操作音         | ダイスやコインを振る音、カードを引く・混ぜる音、コマやダイスを持ち上げる・置く音、ロック、片付け                 |
| 演出の効果音   | マップ演出の音、HPなどが増えたり減ったりしたときの音                                                             |
| その他の効果音 | ジュークボックスのSE、ノベルモードの効果音、ホットバーやスイッチで鳴らす部屋に追加した音など、上のどれでもない音 |

各行の左のボタンを押すと、その種類の音を消せます。もう一度押すと、消す前の音量に戻ります。消しているあいだは、ボタンが赤くなり、スライダーが薄くなります。

実際に聞こえる大きさは、それぞれの値に部屋の音量を掛けたものです。

## チャットの通知音

チャット設定の発言の効果音と同じ設定です（[発言があったら音で知らせる](/manual/chat#発言があったら音で知らせる)）。どちらで変えても、同じ値が動きます。ここで決めた音量には、さらに「通知音」のスライダーが掛かります。

## 部屋の音量

部屋の全員に効く音量です。動かせるのはGMだけで、ほかの参加者には値だけが見えます。ジュークボックスの「部屋の音量」と同じものです。
